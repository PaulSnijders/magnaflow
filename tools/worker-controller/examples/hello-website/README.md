# hello-website — example target project

A complete, minimal target project for `mf-worker`: three commands (`docs/prompts/`) that let
an AI agent build a hello-world website (page → styling → about page).

Don't run mf-worker here — this folder lives inside the magnaflow repo. Copy it to its
own git repository first; see [../../EXAMPLES.md](../../EXAMPLES.md) for the walkthrough.
